# Air Touch Interface
The Air Touch Interface is a real-time human-computer interaction system that allows users to control their computer without physical contact, using only hand gestures captured through a webcam.  This project leverages computer vision and hand tracking to transform the user’s hand into a virtual input device. By tracking specific finger landmarks, the system maps hand movements to cursor control and interprets gestures (such as pinch) as mouse actions like clicking.  The interface provides a smooth and intuitive user experience through motion filtering and gesture detection, enabling precise cursor movement and reliable interaction in real time.
